# Fourhands for Mac

Releases and update feed for [Fourhands](https://joshshaji.github.io/fourhands-releases/), which gives your coding agents their own copies of your Mac apps.

- Download: [Apple silicon](https://github.com/joshshaji/fourhands-releases/releases/latest/download/Fourhands-arm64.dmg) · [Intel](https://github.com/joshshaji/fourhands-releases/releases/latest/download/Fourhands-x64.dmg)
- Installed copies update themselves from this repository's latest release.
