# Twin for Mac

Releases and update feed for [Twin](https://joshshaji.github.io/twin-releases/), which gives your coding agents their own copies of your Mac apps.

- Download: [Apple silicon](https://github.com/joshshaji/twin-releases/releases/latest/download/Twin-arm64.dmg) · [Intel](https://github.com/joshshaji/twin-releases/releases/latest/download/Twin-x64.dmg)
- Installed copies update themselves from this repository's latest release.
- [Terms](https://joshshaji.github.io/twin-releases/terms.html) · [Privacy](https://joshshaji.github.io/twin-releases/privacy.html) · Support: open an issue.
